# Système d'Archivage - Trust Handling Company (THC)

Application web légère et moderne conçue pour centraliser, classer et archiver les documents administratifs, comptables et opérationnels de **Trust Handling Company (THC)**.

## 🚀 Fonctionnalités
- **Gestion dynamique des dossiers et sous-dossiers :** Organisation par catégories principales (Administration, Comptabilité, Audits, Contrats, Rapports, Factures) avec possibilité d'ajouter des sous-dossiers personnalisés.
- **Upload cloud sécurisé :** Enregistrement des fichiers (PDF, Word, Excel, Images, etc.) directement sur **Firebase Storage**.
- **Base de données en temps réel :** Stockage des métadonnées (titres, dates, descriptions, liens) via **Cloud Firestore**.
- **Interface multilingue :** Support complet du Français et de l'Anglais.
- **Recherche instantanée :** Filtrage dynamique des archives par mots-clés, titres, types de fichiers ou dossiers.
- **Gestion complète :** Possibilité de modifier ou supprimer des archives existantes en un clic.

## 🛠️ Technologies utilisées
- **Frontend :** HTML5, CSS3, JavaScript (Modules ES6)
- **Hébergement :** GitHub Pages
- **Backend & Stockage :** Firebase (Firestore & Storage)

## 📌 Utilisation
1. Ouvrez l'application via le lien de déploiement (GitHub Pages ou votre domaine personnalisé).
2. Sélectionnez ou créez un sous-dossier si nécessaire.
3. Remplissez le formulaire (Titre, date, description).
4. Glissez-déposez votre document dans la zone dédiée.
5. Cliquez sur **Enregistrer dans les archives**.
